## 怎么读这组数据

三层的口径不同，**不要混用**：

| 指标 | 口径 | 用途 |
|---|---|---|
| QPS | 网关 | 容量规划 |
| P99 | 端到端 | 体验验收 |

> 采样窗口是 5 分钟，短于一次发布的观察期。

1. 先看 P99 有没有回归
2. 再看 QPS 是否被限流

排队长度只取决于到达率与停留时间：

$$
Q = \lambda W
$$

```bash
hey -z 30s -c 50 https://example.com/api
```

---

*采样窗口*短于一次发布的观察期，所以这组数字只对当前版本成立。

压测脚本见 [示例仓库](https://example.com/bench "压测脚本")。
