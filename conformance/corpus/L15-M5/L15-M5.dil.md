**A2UI（Agent-to-User Interface）使用 JSON，而不是 JSX。**

它是一种让 LLM 通过声明式 JSON 描述 UI，再由客户端渲染成实际界面的协议。

根据 A2UI 官方规范，v0.9.1 是当前生产版本，v1.0 处于 Candidate 阶段，两者都以 JSON 为核心。<Cite refs={["turn516876search7","turn516876search0"]}/>

### JSON vs JSX

| 维度 | A2UI（JSON） | JSX |
|---|---|---|
| LLM 输出 | JSON 消息 | JSX 代码 |
| UI 描述 | 声明式组件数据 | 类 HTML 的组件语法 |
| 渲染方式 | Renderer 解析 JSON | React 等框架渲染 |
| 跨平台 | Web、Flutter 等 | 主要依赖对应框架 |
| 安全性 | 只允许预定义组件和行为 | JSX 通常涉及 JS 运行环境 |
| 流式输出 | 原生支持增量更新 | 需要额外实现 |
