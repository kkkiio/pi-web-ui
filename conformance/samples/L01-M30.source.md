## 一、最有价值的发现：已有 A2UI 实测数据

我找到 Thesys 发布的 <Link url="https://www.openui.com/benchmarks" title="Generative UI Benchmark"/>。

这是目前最接近你问题的公开测试。它比较了 OpenUI、Google A2UI v0.9 和 Vercel json-render 三种 UI 描述格式。

测试覆盖 46 个界面需求，每个模型运行 184 次，并调用相应 SDK 检查输出的结构有效性。

这说明：

- GPT-5.6 Sol 已经能够相当可靠地生成有效 A2UI。
- 至少在这组测试中，OpenAI 模型并不比 Google 自家的 Gemini 差。
- Claude Opus 4.8 甚至超过了二者。

**但请注意：96.2% 是结构有效率，不是功能完成率，也不是视觉设计质量评分。**

测试发布方本身开发 OpenUI，存在商业利益关系；不过它公开了测试代码、原始输出和评分结果，可以复核。

因此，这是一份有价值但不能单独决定选型的证据。

  </box>

其公开开发记录称：

- 使用 `gpt-6-astra` 生成 UI 规范。
- 集成 A2UI-Swift 渲染器。
- Wikipedia 网页转换后在 macOS 应用中成功渲染。
- IANA 网页转换通过后端产物验证，但当时尚未完成对应的原生渲染核验。

这是一份**确实把 GPT-6 系列与 A2UI 放在一起使用的案例**，不是单纯的产品概念。<Cite ref="turn296041view4"/>

但证据等级仍然有限：属于开发者自述的项目验证，而不是多模型对照 Benchmark。并且使用的是 **GPT-6 Astra**，不能把它的表现直接套用到这次 ChatGPT Intelligent UI 使用的 GPT-6 Sol。

## 四、如果现在开发 A2UI 应用，我会怎么选？

| 场景 | 我的建议 |
|---|---|
| 想验证 GPT-6 能否生成 A2UI | 值得测试 |
| 想先选一个结构可靠的模型 | Claude Opus 4.8、GPT-5.6 Sol 都有不错的已有测试依据 |
| 对延迟、成本敏感 | 同时测试 Gemini Flash |
| 想复用 ChatGPT Intelligent UI | 目前没有证据表明可以直接导出为 A2UI |
| 准备投入生产 | 必须接入 A2UI Schema 校验、错误修复和交互测试 |

还有一个容易忽略的问题：

**GPT-6 能生成漂亮的界面，不代表它能持续生成符合特定 A2UI 版本规范的 JSON。**

我会重点测试这四项：首次生成的 Schema 通过率、多轮修改时的组件状态保持、交互动作是否正确，以及流式渲染时是否出现无效引用。

我的推断是：GPT-6 经过 UI 布局与交互方面的专项训练，可能在理解用户需要什么界面方面有优势。但这种优势能否迁移到 Google A2UI，还需要针对 A2UI 的专项测试。

**如果你的目的是开发自己的 Generative UI 产品，我不会因为 GPT-6 发布了 Intelligent UI 就直接选 GPT-6。** 我会把 GPT-6 Sol、Claude Opus 和 Gemini 放在同一套 A2UI 测试中比较，再决定。

现在最缺的不是演示视频，而是一份 **GPT-6 Sol vs Gemini vs Claude 的 A2UI 专项实测**。

这次发布还很新。我也可以持续关注 GitHub、Reddit 和新的 Benchmark，等出现 GPT-6 的直接对比成绩时告诉你。
